# Hospital Management System

This repository contains a web-based Hospital Management System for patients, doctors, nurses, receptionists, accountants, and administrators.

The project has a React/Vite frontend and a Node.js/Express backend using MongoDB, JWT authentication, Socket.IO, and Cloudinary.
